# AI Business Idea Validator

An AI-based web application that helps students and aspiring entrepreneurs evaluate their startup ideas.

## What it does

- Identifies target customers
- Finds potential competitors
- Defines the problem
- Suggests possible solutions
- Highlights potential risks

## Example

A food delivery service designed specifically for college students.

## Technologies

- HTML
- CSS
- JavaScript
- Generative AI
